## 2. MP3 音频数据流（从 SD 卡到扬声器）

```text
┌──────────────────────────────────────────────────────────────────────┐
│                     MP3 音频数据管道                                   │
│                                                                       │
│  ┌─────────┐     ┌──────────────┐     ┌──────────────┐               │
│  │  SD 卡  │     │  PSRAM       │     │  PSRAM       │               │
│  │         │     │  MP3 Read    │     │  PCM         │               │
│  │ song.mp3│────→│  Buffer      │────→│  RingBuffer  │               │
│  │         │     │  64~128KB    │     │  128~256KB   │               │
│  └─────────┘     └──────────────┘     └──────┬───────┘               │
│       │               ↑                      │                       │
│       │  SDMMC + DMA  │ CPU/FATFS/文件系统     │ CPU 分块搬运          │
│       ▼               │                      ▼                       │
│  ┌──────────────┐     │               ┌──────────────┐               │
│  │  SRAM        │     │               │  SRAM        │               │
│  │  SD DMA      │─────┘               │  I2S DMA     │               │
│  │  Buffer      │                     │  Buffer      │               │
│  │  8~16KB      │                     │  16~32KB     │               │
│  └──────────────┘                     └──────┬───────┘               │
│                                              │ I2S + DMA             │
│                                              ▼                       │
│                                       ┌──────────────┐               │
│                                       │  ES8311      │               │
│                                       │  DAC + 功放   │               │
│                                       └──────┬───────┘               │
│                                              │                       │
│                                              ▼                       │
│                                       ┌──────────────┐               │
│                                       │   扬声器 🔊   │               │
│                                       └──────────────┘               │
│                                                                       │
│  ┌─ 数据流动 ────────────────────────────────────────────────────┐   │
│  │                                                                │   │
│  │  步骤1: SDMMC DMA 搬 1 块 → SRAM SD Buffer                    │   │
│  │  步骤2: CPU 从 SRAM SD Buffer → PSRAM MP3 Read Buffer(累积)   │   │
│  │  步骤3: CPU 从 MP3 Read Buffer 取数据 → Mp3Decoder → PCM      │   │
│  │  步骤4: CPU 写 PCM → PSRAM PCM RingBuffer                     │   │
│  │  步骤5: CPU 从 PCM RingBuffer 取 → SRAM I2S DMA Buffer        │   │
│  │  步骤6: I2S DMA 从 SRAM Buffer → ES8311 → 功放 → 扬声器      │   │
│  │                                                                │   │
│  │  DMA 只搬最后一段(步骤1和6)，中间解码全由 CPU 做                │   │
│  └────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. GIF / UI 显示数据流（从 Flash 到屏幕）

```text
┌──────────────────────────────────────────────────────────────────────┐
│                     GIF / UI 显示数据管道                              │
│                                                                       │
│  ┌──────────────┐                                                     │
│  │ Flash 内置   │  ui.gif  (播放动画 / 暂停动画)                       │
│  │ assets 分区  │                                                     │
│  └──────┬───────┘                                                     │
│         │ CPU 读取或 mmap                                             │
│         ▼                                                            │
│  ┌──────────────┐     ┌──────────────┐     ┌──────────────┐          │
│  │  PSRAM       │     │  PSRAM       │     │  SRAM        │          │
│  │  GIF 文件缓存 │────→│  GIF 当前帧   │────→│  LCD DMA     │          │
│  │  64~512KB    │     │  RGB565      │     │  Buffer A/B  │          │
│  └──────────────┘     │  50~150KB    │     │  ~51KB       │          │
│                       └──────────────┘     └──────┬───────┘          │
│                             ↑                      │                  │
│                       CPU GIF Decoder              │ QSPI + DMA       │
│                       (解 GIF→RGB565)              ▼                  │
│                                             ┌──────────────┐          │
│                                             │  AMOLED      │          │
│                                             │  368×448     │          │
│                                             │  局部刷新     │          │
│                                             └──────────────┘          │
│                                                                       │
│  ┌─ 关键决策 ────────────────────────────────────────────────────┐   │
│  │                                                                │   │
│  │  GIF 放 Flash 不占 SD 卡带宽 → 音频读 SD 时不抢总线             │   │
│  │  LCD 只刷 GIF 局部区域(如 160×160)，不全屏刷新                  │   │
│  │  双缓冲 A/B 交替：一块在 DMA 传输，一块 CPU 在填充              │   │
│  │  帧率由 PCM 水位动态决定：                                      │   │
│  │    PCM > 60%  →  GIF 10~15 FPS (正常)                         │   │
│  │    PCM 30~60% →  GIF 5~8 FPS  (降帧)                         │   │
│  │    PCM < 30%  →  GIF 暂停      (保音频)                       │   │
│  └────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────┘
```

## 一句话总结

```text
触摸/按键 ──事件──→ App FSM ──命令──→ AudioPlayer ──PCM──→ I2S ──→ 🔊
                         │
                         └──事件──→ UiTask ──RGB565──→ QSPI ──→ 📺
                                        │
                                   GifPlayer (按 PCM 水位自动降帧)

所有模块解耦，只走 Queue，不直接互调。
PSRAM 存大对象，SRAM 存 DMA 缓冲，启动时一次性分配。
音频优先级最高，GIF 可降级但不能断音。
```
