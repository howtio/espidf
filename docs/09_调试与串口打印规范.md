# 调试与串口打印规范

> USB Serial (GPIO19/20) 是调试的生命线。所有模块必须遵循统一的日志格式和等级规范。
> Claude 开发时也必须大量打串口日志，方便实时观察和定位问题。

---

## 1. 串口日志格式

```text
[HH:MM:SS.mmm] [LEVEL] [MODULE] message
```

| 字段 | 格式 | 说明 |
|------|------|------|
| 时间戳 | `12:34:56.789` | 系统启动后毫秒级时间 |
| LEVEL | `TRC/DBG/INF/WRN/ERR` | 日志等级 |
| MODULE | 3~5字符 | 模块标识 |
| message | 自由文本 | 一行，不换行 |

### 示例

## 2. 日志等级定义

| 等级 | 标识 | 用途 | 生产环境 |
|------|------|------|----------|
| TRACE | `TRC` | 函数进入/退出、每帧细节 | 关闭 |
| DEBUG | `DBG` | 水位/帧率/内存等周期数据 | 关闭 |
| INFO | `INF` | 状态变更、操作完成、启动信息 | 保留 |
| WARN | `WRN` | 降级触发、水位告警、重试 | 保留 |
| ERROR | `ERR` | 硬件错误、解码失败、SD异常 | 保留 |

---

## 3. 模块标识

| 标识 | 模块 | 职责 |
|------|------|------|
| `SYS` | SystemMonitor | 启动、硬件初始化、系统信息 |
| `AUDIO` | AudioPlayer | 播放控制、水位、命令 |
| `MP3` | Mp3Decoder | 解码耗时、帧信息 |
| `SD` | StorageManager | SD 挂载、文件读取 |
| `LCD` | DisplayManager | 显示初始化、刷屏 |
| `GIF` | GifPlayer | GIF 帧解码、降级 |
| `TOUCH` | TouchManager | 触摸坐标、手势 |
| `BTN` | ButtonManager | 按键事件 |
| `PL` | Playlist | 歌曲列表、索引 |
| `MEM` | MemoryPool | 内存分配、余量 |
| `PWR` | PMU/电源 | 电池、充电状态 |
| `FSM` | App FSM | 状态流转、事件分发 |
| `QUEUE` | Queue | 队列满/空告警 |

## 4. Claude 开发时必须打印的内容

### 4.1 每个模块初始化时必须打印

```cpp
// 成功
LOG_INF("SYS", "%s: 初始化成功 (版本 %d.%d.%d)", component, maj, min, pat);

// 失败
LOG_ERR("SYS", "%s: 初始化失败! 错误码: 0x%04X", component, err);
```

### 4.2 每个状态变更必须打印

```cpp
LOG_INF("FSM", "状态: %s → %s (触发事件: %s)", old_state, new_state, event);
```

### 4.3 周期数据（每 5 秒一次）

```cpp
LOG_DBG("MEM", "SRAM free:%4uKB min:%4uKB | PSRAM free:%5uKB min:%5uKB", ...);
LOG_DBG("PWR", "电池:%3u%% | 状态:%s | 电压:%.2fV", ...);
LOG_DBG("AUDIO", "PCM水位:%3u%% | 当前帧:%4u | 解码耗时:%3.1fms", ...);
LOG_DBG("GIF", "帧#%3u | 解码:%3.1fms | FPS:%2u | 水位:%3u%%", ...);
```

### 4.4 异常/边界情况必须打印

```cpp
LOG_WRN("QUEUE", "%s 队列使用率 > 80%%: %u/%u", qname, used, capacity);
LOG_WRN("AUDIO", "PCM 水位跌至 %u%%, 触发降级", water_level);
LOG_ERR("SD", "读取超时: %s (扇区 %lu)", path, sector);
LOG_ERR("MP3", "解码失败: 帧#%u, 跳过 (sync lost)", frame_no);
```

## 5. LOG 宏定义

```cpp
// debug_log.h — 所有模块统一引用

#pragma once
#include "esp_log.h"
#include <cstdio>

// 统一的日志 TAG 格式: "MODULE"
#define LOG_TRC(mod, fmt, ...) ESP_LOGD(mod, "[TRC] " fmt, ##__VA_ARGS__)
#define LOG_DBG(mod, fmt, ...) ESP_LOGD(mod, "[DBG] " fmt, ##__VA_ARGS__)
#define LOG_INF(mod, fmt, ...) ESP_LOGI(mod, "[INF] " fmt, ##__VA_ARGS__)
#define LOG_WRN(mod, fmt, ...) ESP_LOGW(mod, "[WRN] " fmt, ##__VA_ARGS__)
#define LOG_ERR(mod, fmt, ...) ESP_LOGE(mod, "[ERR] " fmt, ##__VA_ARGS__)

// 生产环境可以全局关闭 DBG/TRC:
// #define LOG_DBG(mod, fmt, ...) ((void)0)
// #define LOG_TRC(mod, fmt, ...) ((void)0)
```

## 6. 屏幕上的系统状态栏（SystemMonitor 驱动）

```text
┌──────────────────────────────────────────┐
│ 🔋85% 放电   SRAM:234KB  PSRAM:6.1MB    │  ← 顶部状态栏 32px
├──────────────────────────────────────────┤
│                                          │
│          ┌──────────────┐                │
│          │              │                │
│          │  电子宠物     │  160×160      │
│          │  (GIF)       │                │
│          │              │                │
│          └──────────────┘                │
│                                          │
│    ♪ 01 - 歌曲名称.mp3                   │
│    ████████░░░░░░░░ 1:30/4:32           │
│                                          │
│      ⏮      ▶/⏸      ⏭                 │
│                                          │
└──────────────────────────────────────────┘

状态栏由 SystemMonitor 每 5 秒更新一次:
  电池: 读取 AXP2101 → 百分比 + 充/放电状态
  内存: 读取 MemoryPool → SRAM 剩余 / PSRAM 剩余
  充电时显示: ⚡85% 充电中
```

状态栏显示内容：

| 位置 | 内容 | 来源 | 刷新间隔 |
|------|------|------|----------|
| 左侧 | 电池图标 + 百分比 + 充/放 | AXP2101 I2C | 5s |
| 右侧 | SRAM:XXXKB | MemoryPool | 5s |
| 右侧 | PSRAM:X.XMB | MemoryPool | 5s |

## 7. Claude 调试检查清单

每次写代码后必须能在串口看到：

```
□ 启动全景打印 (所有硬件初始化状态)
□ 每个状态流转打印 (IDLE→PLAYING, PLAYING→PAUSED 等)
□ 每 5 秒周期打印 (内存/电量/PCM水位/GIF帧率)
□ 每个触摸/按键事件打印
□ 每个 Queue 操作打印 (TRACE 级别)
□ 每个错误打印 (含错误码)
□ 降级/恢复打印 (水位触发)
```

如果串口看不到这些日志，说明调试基础设施没跑通，不能算完成。

## 8. 调试命令（通过串口发送）

后续可以支持通过串口发送单字符命令来触发调试动作：

| 命令 | 作用 |
|------|------|
| `m` | 打印一次内存详情 |
| `p` | 打印一次电量详情 |
| `w` | 打印 PCM 水位 |
| `g` | 打印 GIF 帧率/降级状态 |
| `s` | 打印当前状态机状态 |
| `f` | 打印 FreeRTOS 任务栈余量 |
| `h` | 打印帮助 |
