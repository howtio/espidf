# 开发计划

> 渐进式分阶段开发。每个 Phase 独立可验证，Phase 内再拆小步。
> 每个 Phase 必须包含串口调试日志，Claude 靠 idf.py monitor 观察。

---

## Phase 概览

```text
Phase 1: 基础可用          🟢 项目骨架 + 编译链路 + 串口最小输出
Phase 2: 屏幕 + 触摸       🔴 点亮屏 + 读触摸 + 状态栏占位
Phase 3: SD + I2S 环路     🔴 挂载 SD + I2S 测试音 + 电池读取
Phase 4: MP3 播放          🔴 解码 + PCM 输出 + 周期日志
Phase 5: GIF 电子宠物       🔴 GIF 解码 + 水位降级 + 完整状态栏
Phase 6: 完整交互          🔴 App FSM + 全部 UI + 全量日志
Phase 7: 打磨              🔴 性能优化 + 异常恢复 + UI 美化
```

**目标：** 屏幕点亮 + 触摸坐标可读 + 状态栏占位 + 驱动顺序验证

## Phase 4：MP3 播放

**目标：** SD 卡读 MP3 → 解码 → I2S 播放 + 周期日志

**任务清单：**
- [ ] MemoryPool：一次性分配所有 SRAM/PSRAM 缓冲，打印分配结果
- [ ] MP3 解码器集成 (libmad 或 helix)
- [ ] MP3 ReadBuf (PSRAM 128KB) + PCM RingBuf (PSRAM 256KB)
- [ ] I2S DMA Buffer (SRAM 32KB)
- [ ] AudioTask：读文件 → 解码 → 喂 PCM RingBuf → I2S 输出
- [ ] 周期打印：PCM 水位 + 内存余量 (每 5 秒)
- [ ] 基础播放控制：play(file)、stop()

**验收标准：** 指定一个 MP3 文件路径，扬声器听到音乐

**调试日志：**

## Phase 5：GIF 电子宠物

**目标：** 屏幕显示电子宠物 GIF + 音频水位降级 + 完整状态栏

**任务清单：**
- [ ] GIF 解码器集成
- [ ] GIF 当前帧缓冲 + 4~5 帧窗口缓存 (PSRAM)
- [ ] GIF 资源内置到 Flash `assets` SPIFFS 分区
- [ ] LCD DMA 双缓冲 (SRAM ~51KB)
- [ ] 局部刷新 — 只刷 GIF 160×160 区域
- [ ] 帧率控制 — 目标 10fps
- [ ] 音频水位监控 + GIF 降级策略
- [ ] 状态栏显示：电池 + SRAM + PSRAM + GIF 降级等级
- [ ] 播放/暂停时切换 GIF

**验收标准：** 播音乐时 GIF 动画正常，音频不断，状态栏实时更新

**调试日志：**
