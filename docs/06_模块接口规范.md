# 模块接口规范

> 解耦开发的契约文档。每个模块只暴露 `.hpp` 公开接口，实现细节藏在 `.cpp`。
> 模块间只通过 Queue 通信，不直接互调。接口变更必须更新本文档。

---

## 1. AudioPlayer

```cpp
// AudioPlayer.hpp — 播放控制中枢
#pragma once
#include "freertos/FreeRTOS.h"
#include "freertos/queue.h"

enum class AudioState { Stopped, Playing, Paused, Loading, Error };

struct AudioPlayerConfig {
    size_t mp3_read_buffer_size;     // PSRAM, 默认 128KB
    size_t pcm_ringbuffer_size;      // PSRAM, 默认 256KB
    size_t i2s_dma_buffer_size;      // SRAM, 默认 32KB
    int sample_rate;                 // 默认 22050
    int bits_per_sample;             // 默认 16
    int channels;                    // 默认 1 (mono)
};

class AudioPlayer {
public:
    bool init(const AudioPlayerConfig& cfg, QueueHandle_t cmd_queue, QueueHandle_t event_queue);
    void deinit();

    AudioState state() const;
    float pcm_water_level() const;   // 0.0 ~ 1.0
    int current_volume() const;      // 0 ~ 100

    [[noreturn]] void task_loop();
};
```

## 10. SystemMonitor (🆕)

```cpp
// SystemMonitor.hpp — 系统状态采集 + 串口日志 + 屏幕状态栏
#pragma once
#include "freertos/queue.h"
#include <cstdint>

struct SystemStatus {
    // 电源
    bool is_charging;           // true=充电中, false=放电
    bool usb_connected;         // USB VBUS 是否接入
    uint8_t battery_percent;    // 0~100
    float battery_voltage;      // 电压 (V)

    // 内存
    size_t sram_free;           // SRAM 剩余字节
    size_t sram_min_free;       // SRAM 历史最低
    size_t psram_free;          // PSRAM 剩余字节
    size_t psram_min_free;      // PSRAM 历史最低

    // 音频
    float pcm_water_level;      // PCM RingBuf 水位 0.0~1.0

    // GIF
    int gif_fps;                // 当前 GIF 帧率
    const char* gif_level;      // "FULL"/"REDUCED"/"MINIMAL"
};

class SystemMonitor {
public:
    static SystemMonitor& instance();

    bool init(QueueHandle_t ui_event_queue);
    void deinit();

    // 采集一次系统状态 (由 LogTask 每 5 秒调用)
    SystemStatus collect();

    // 串口打印启动全景 (初始化完成后调用一次)
    void print_boot_banner();

    // 串口打印一条状态 (每 5 秒调用一次)
    void print_status(const SystemStatus& st);

    // 串口日志接口 (所有模块统一调用)
    static void log(const char* level, const char* module,
                    const char* fmt, ...);

    [[noreturn]] void task_loop();  // 每 5 秒采集 + 打印 + 更新状态栏
};
```

**SystemMonitor 串口日志格式：**

```text
[HH:MM:SS.mmm] [LEVEL] [MODULE] message

LEVEL:  TRC | DBG | INF | WRN | ERR
MODULE: SYS | AUDIO | MP3 | SD | LCD | GIF | TOUCH | BTN | PL | MEM | PWR | FSM | QUEUE
```
