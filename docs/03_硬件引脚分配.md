# 硬件引脚分配

> 来源：官方 BSP + 原理图交叉核对。所有引脚定义在 `config/board_config.h`。

---

## 1. I2C 总线

| 信号 | GPIO | 说明 |
|------|------|------|
| `I2C_SCL` | `GPIO14` | 时钟 |
| `I2C_SDA` | `GPIO15` | 数据 |

共用此总线的器件：

| 器件 | 型号 | 地址 | 用途 |
|------|------|------|------|
| 触摸 | FT3168 | `0x38` | 电容触摸输入 |
| RTC | PCF85063 | `0x51` | 实时时钟 |
| IMU | QMI8658 | `0x6B` | 6 轴惯导 |
| PMU | AXP2101 | `0x34` | 电源管理 |
| IO 扩展 | TCAL9534 | `0x20` | 复位/电源/CS 辅助控制 |
| 音频 Codec | ES8311 | `0x18` | 音频控制面 |

---

## 2. LCD 显示（QSPI 类总线）

| 信号 | GPIO | 说明 |
|------|------|------|
| `LCD_CS` | `GPIO12` | 片选 |
| `LCD_PCLK` | `GPIO11` | 时钟 |
| `LCD_DATA0` | `GPIO4` | 数据线 D0 |
| `LCD_DATA1` | `GPIO5` | 数据线 D1 |
| `LCD_DATA2` | `GPIO6` | 数据线 D2 |
| `LCD_DATA3` | `GPIO7` | 数据线 D3 |
| `LCD_TE` | `GPIO13` | Tear Effect 同步 |

分辨率：**368×448**（以官方产品页为准）

IO 扩展器辅助控制：

| Bit | 信号 | 说明 |
|-----|------|------|
| `bit0` | `LCD_RST` | 显示屏复位 |
| `bit1` | `DSI_PWR_EN` | 屏电源使能 |
| `bit2` | `TOUCH_RST` | 触摸复位 |

---

## 3. 触摸

| 信号 | 连接 |
|------|------|
| `TP_SCL` | 共用 `GPIO14` |
| `TP_SDA` | 共用 `GPIO15` |
| `TP_INT` | `GPIO21` |
| `TP_RST` | IO 扩展器 `bit2` |

---

## 4. I2S 音频

| 信号 | GPIO | 说明 |
|------|------|------|
| `I2S_MCLK` | `GPIO16` | 主时钟 |
| `I2S_BCLK` | `GPIO9` | 位时钟 |
| `I2S_LRCK` | `GPIO45` | 左右通道时钟 |
| `I2S_DOUT` | `GPIO8` | 数据输出（播放） |
| `I2S_DIN` | `GPIO10` | 数据输入（录音） |
| `AMP_EN` | `GPIO46` | 功放使能 |

Codec 控制：ES8311 经 I2C（共用 GPIO14/15）

---

## 5. SDMMC（TF 卡）

| 信号 | GPIO | 说明 |
|------|------|------|
| `SD_CMD` | `GPIO1` | 命令线 |
| `SD_CLK` | `GPIO2` | 时钟 |
| `SD_D0` | `GPIO3` | 数据线 D0 |
| `SD_CS` | IO 扩展器 `bit7` | 片选 |

模式：1-bit SDMMC

---

## 6. USB

| 信号 | GPIO |
|------|------|
| `USB_D+` | `GPIO20` |
| `USB_D-` | `GPIO19` |

用途：供电、烧录、日志输出

---

## 7. 初始化顺序

板上多个器件共用 I2C，屏/触摸/TF 的辅助控制依赖 IO 扩展器，启动顺序必须严格：

```
1. I2C 总线初始化
2. IO 扩展器初始化（释放复位）
3. 放开 TOUCH_RST（bit2）
4. 放开 LCD_RST（bit0）+ DSI_PWR_EN（bit1）
5. 初始化 LCD 显示驱动
6. 初始化触摸驱动
7. 初始化 SDMMC
8. 初始化 I2S + ES8311
9. 挂载文件系统
10. 创建 FreeRTOS 任务
```
