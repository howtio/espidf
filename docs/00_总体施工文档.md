# 总体施工文档

> esp32-mp3-player 项目基准文档。新开发先读本文件，再读 `01_架构说明.md` 和 `09_调试与串口打印规范.md`。

---

## 1. 项目定义

```text
esp32-mp3-player = 触摸屏 MP3 播放器，带电子宠物 GIF 动画 + 系统状态监控。

  SD 卡 (MP3 文件) → ESP32-S3 → I2S 音频输出 + LCD 显示 + 触摸交互
                                 + USB Serial 调试日志
```

核心体验：
- 从 SD 卡读取 MP3 文件播放（mono 22050Hz 64kbps，优化格式）
- 播放界面显示电子宠物 GIF 动画（160×160, 10fps）
- **屏幕顶部状态栏**：电池电量 + 充放电状态 + SRAM/PSRAM 使用率
- 触摸屏操作：播放/暂停、上一首/下一首
- 音频不中断优先，UI 在资源紧张时可降级
- **USB 串口全量调试日志**：启动全景、状态流转、周期水位、异常告警

## 2. 屏幕 UI 布局

```text
┌──────────────────────────────────────────┐
│ 🔋85% 放电   SRAM:234KB  PSRAM:6.1MB    │  ← 状态栏 32px (SystemMonitor)
├──────────────────────────────────────────┤
│                                          │
│          ┌──────────────┐                │
│          │              │                │  ← GIF 区域 160×160
│          │  电子宠物     │                │     (GifPlayer)
│          │  (GIF动画)   │                │
│          │              │                │
│          └──────────────┘                │
│                                          │
│    ♪ 01 - 歌曲名称.mp3                   │  ← 歌曲信息
│    ████████░░░░░░░░ 1:30/4:32           │  ← 进度条
│                                          │
│      ⏮      ▶/⏸      ⏭                 │  ← 控制按钮
│                                          │
└──────────────────────────────────────────┘
```

状态栏每 5 秒刷新一次，由 SystemMonitor 驱动，数据来源：
- 电池：AXP2101 PMU (I2C 0x34)
- 内存：MemoryPool（SRAM free / PSRAM free）

└─────┬─────┘     └──────┬───────┘     └───────┬─────────┘

┌──────────────┐  ┌──────────────┐   ┌────────────────┐

       │                 │           └────────┬───────┘

## 5. 核心模块职责

| 模块 | 能做 | 不能 |
|------|------|------|
| `audio_player` | 播放控制、水位监控、命令消费 | 不解码、不读文件、不刷屏 |
| `mp3_decoder` | MP3→PCM | 不碰硬件、不管文件 |
| `storage_manager` | SD 挂载/卸载、文件扫描、读取 | 不解码、不播放 |
| `display_manager` | LCD + LVGL 驱动、局部刷新 | 不解码 GIF、不处理触摸 |
| `gif_player` | GIF 解码、帧率控制、水位降级 | 不管理屏幕驱动层 |
| `touch_manager` | I2C 读坐标、发送触摸事件 | 不决策、不刷屏 |
| `button_manager` | GPIO 消抖、发送按键事件 | 不决策 |
| `playlist` | 歌曲列表、当前索引、遍历 | 不读文件、不播放 |
| `memory_pool` | 统一 SRAM/PSRAM 分配 | 不参与业务逻辑 |
| `system_monitor` | 🆕 电池/内存采集、串口日志、屏幕状态栏 | 不决策、不控制外设 |

## 6. 施工原则

```
1. 音频优先 — PCM RingBuffer 低于阈值时 GIF/UI 降级，音频不能断
2. PSRAM 大水库，SRAM 小水槽 — DMA 缓冲放 SRAM，大对象放 PSRAM
3. 模块间只走 Queue + Event — 不直接互调
4. 运行时不 malloc/free — 启动时一次性分配
5. 先通最小链路 — 再补异常与降级 — 再美化 UI
6. 每次开发必须有远端备份 — 没有备份不写代码
7. 串口即眼睛 — 每段代码必须带日志，Claude 靠串口调试
```
