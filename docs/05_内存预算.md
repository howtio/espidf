# 内存预算

> PSRAM 大水库，SRAM DMA 小水槽。全部在 MemoryPool::init() 一次性分配。

---

## 1. PSRAM 预算（总计 8MB 可用）

| 缓冲区 | 大小 | 用途 |
|--------|------|------|
| MP3 Read Buffer | 128KB | SD→解码器的中转水库 |
| PCM RingBuffer | 256KB | 解码后 PCM，防 I2S 断粮 |
| GIF 当前帧 RGB565 | 150KB | 160×160×2 = 50KB，余量给更大帧 |
| GIF 文件缓存 | 128KB | ui.gif 406KB → 分块解码，缓存区 |
| LVGL 帧缓冲 | ~322KB | 368×448×2 全帧(可降为局部) |
| LVGL UI 对象 | 100KB | 按钮、标签、进度条、状态栏 |
| 系统开销 + 应急 | ~1MB | 堆碎片 + 日志缓冲 |

**PSRAM 合计：** ~2.1MB / 8MB（充足）

---

## 2. SRAM 预算（总计 512KB，精打细算）

| 缓冲区 | 大小 | 用途 |
|--------|------|------|
| I2S DMA Buffer | 32KB | 音频最后输出层 |
| LCD DMA Buffer A | 26KB | 半帧双缓冲 |
| LCD DMA Buffer B | 26KB | 半帧双缓冲 |
| SD DMA Buffer | 16KB | SDMMC 块传输 |
| AudioTask 栈 | 8KB | Core 0 |
| AppTask 栈 | 8KB | Core 1 |
| UiTask 栈 | 8KB | Core 1 |
| TouchTask 栈 | 4KB | Core 1 |
| ButtonTask 栈 | 4KB | Core 1 |
| LogTask 栈 | 4KB | 任意 |
| AppEventQueue | 2KB | 32 × 64B |
| AudioCommandQueue | 1KB | 16 × 64B |
| UiEventQueue | 1KB | 16 × 64B(含 SystemStatus) |
| DMA 描述符 | <1KB | 链表 |
| 日志缓冲 | 2KB | 🆕 串口日志缓冲 |
| 系统保留 | ~100KB | WiFi/BLE 栈 + 系统任务 |

**SRAM 合计：** ~243KB / 512KB（有余量）

---

## 3. 分配策略

```cpp
// 启动时一次性分配，失败则降级或报错
MemoryPool& pool = MemoryPool::instance();
pool.init();

// PSRAM 大缓冲
void* mp3_read_buf  = pool.alloc_psram(128 * 1024);
void* pcm_ring_buf  = pool.alloc_psram(256 * 1024);
void* gif_frame_buf = pool.alloc_psram(150 * 1024);
void* gif_file_buf  = pool.alloc_psram(128 * 1024);
void* lvgl_fb       = pool.alloc_psram(322 * 1024);

// SRAM DMA 缓冲
void* i2s_dma_buf   = pool.alloc_sram(32 * 1024);
void* lcd_dma_a     = pool.alloc_sram(26 * 1024);
void* lcd_dma_b     = pool.alloc_sram(26 * 1024);
void* sd_dma_buf    = pool.alloc_sram(16 * 1024);

// 每步分配后打印:
// [INF] [MEM] PSRAM: MP3 ReadBuf 128KB ✓ (剩余: 7.8MB)
// [INF] [MEM] SRAM: I2S DMA 32KB ✓ (剩余: 480KB)
```

---

## 4. 防爆措施

- 所有 buffer 启动时一次性申请，失败打印 LOG_ERR 并降级
- PCM RingBuffer < 30%：暂停 GIF 解码
- PCM RingBuffer = 0：填静音，避免爆音
- 每 5 秒打印: SRAM free / min_free / PSRAM free / min_free / PCM 水位 / GIF FPS
- Queue 满时丢弃低优先级事件，保留播放控制事件
- LogTask 栈 high water mark 监控
